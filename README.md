# Trigenys Payment Orchestrator

Generic TypeScript API service generated by Trigenys AppFactory.

## Runtime

- Node.js 24
- TypeScript
- native Node HTTP server
- Node test runner
- AppFactory Project Automation
- shared AppFactory release workflow

The blueprint deliberately does **not** choose a database, cloud provider, queue, authentication product or deployment target. Add those only when the service workload requires them.

## Development

```bash
npm install
npm run dev
```

Validation:

```bash
npm run check
```

Production build:

```bash
npm run build
node dist/src/index.js
```

## Endpoints

- `GET /health` → service readiness payload

## RAIDER boundary

The generated service owns its domain logic. Infrastructure choices remain consumer decisions and should be introduced through explicit adapters/configuration rather than hard-coded into the domain core.
